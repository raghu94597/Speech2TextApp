# Speech2TextApp  
Transcribes speech to text using Azure Speech Services and summarizes the output using an LLM.

---

## 📌 Overview
Speech2TextApp is a simple project that converts spoken audio into text and then processes the transcription using a Large Language Model (LLM).  
This repository also documents the full Git/GitHub workflow used to create and publish the project, so beginners can follow the same steps.

---

## 🎤 Features
- Converts speech to text using Azure Cognitive Services  
- Processes the transcription using an LLM  
- Simple folder structure  
- Easy to run locally  
- Beginner‑friendly Git/GitHub workflow included
